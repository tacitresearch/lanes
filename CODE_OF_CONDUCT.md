# Code of conduct

Lanes follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour to the maintainers privately: through GitHub's private reporting
on this repository (Security → Report a vulnerability, marked as a conduct report), or to the
maintainers' contact address once it is listed here. Reports are kept confidential.
