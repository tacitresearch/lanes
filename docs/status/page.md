in `docs/status/` (`areas/<area>.md`, `apps/<app>.md`), and the rest of this page is
`docs/status/page.md`. A section's first line is its heading; each item is one line, and
`lake exe lanes lint --fix` sorts each list and writes this page. Two changes to different
items then touch different lines. Update a section in the same change that moves an item.
