# Changes before the first release

No pull request adds a file here any more: the changelog is written when a release is cut
(`CONTRIBUTING.md`, `docs/RELEASING.md`). The files here are raw material for the first
release's notes; `lake exe lanes changelog --release X.Y.Z YYYY-MM-DD` gathers them, and the
folder goes after that release. `lanes lint` still checks that each file reads (lint
`changelog`).
