### Added

- A decision, `docs/decisions/new-runtime-contract.md`: one model with proofs, and runtimes proved against it. The contract is a Lean structure, experimental until the multi-core runtime implements it: a runtime's events are a run of the semantics, outputs are handed over at least once with stable ids for idempotency keys, no acknowledged input is lost, a quarantined input counts as one that never arrived, and what it holds is a state of the run. Theorems' premises about the environment get names (`Faultless`, `InputsOnce`, `NoDuplicates`, `Ordered`, `Lossless`, `Up`, `Fair`), and each runtime says which it provides. It also decides the default runtime (one journal, the gate off the hot path, reads from the state, waves after `examples/videos` is split per user, local journal files with sealed segments shipped to S3, later hibernation and a standby), one runtime value per application (`Lanes.run app runtime`) in a package of its own, and tests the contract against a runtime after Durable Objects. No code changes.
